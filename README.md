# داشبورد ایجنتیک تایلندگرد

وب‌اپ Next.js برای مدیریت ۱۵ تیم هوش مصنوعی تایلندگرد. این داشبورد جایگزین ارکستراسیون n8n می‌شود و کل چرخه‌ی اجرا، نظارت و گزارش تیم‌ها را یک‌جا جمع می‌کند.

## معماری کلی

- **۱۵ تیم ایجنت**: تیم‌های تخصصی (هنر، برند، محتوا، سئو، تحلیل، اینتل، لید، دیزاین، محتوای سئومحور، وایب‌فارسی، رابط فارسی، دیزاین-ایران، توسعه، کیو‌ای و اینسپکتور) که به‌ترتیب مشخص در هر چرخه اجرا می‌شوند.
- **موج‌های اجرا (Waves)**: ۱۵ تیم در ۶ موج پشت سر هم اجرا می‌شوند؛ موج اول (که سه‌تیمه بود) به دو موج تقسیم شده تا بار اجرا متعادل شود. تعریف موج‌ها در `lib/types.ts` (ثابت `WAVES`) است.
- **چرخه (Cycle)**: هر اجرای کامل، یک سایکل است با وضعیت‌های `running`، `success`، `failed` و `canceled`. هر تیم در هر چرخه یک `TeamRun` دارد با وضعیت `pending`، `running`، `success`، `failed` یا `skipped`.
- **داشبورد**: صفحه‌ی `app/dashboard` وضعیت زنده‌ی چرخه‌ی جاری، هر تیم و هر موج را نشان می‌دهد.
- **حافظه‌ی تیم‌ها**: هر تیم می‌تواند ورودی‌های حافظه (کلید/مقدار) ثبت کند تا بین چرخه‌ها حفظ شود.
- **صف وظایف**: خروجی هر تیم می‌تواند شامل وظایف پیشنهادی با اولویت باشد که وارد صف می‌شوند.

## راهنمای نصب

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. ساخت فایل محیطی
cp .env.example .env.local
# بعد کلیدها را داخل .env.local بگذار:
# NEXT_PUBLIC_SUPABASE_URL=...
# NEXT_PUBLIC_SUPABASE_ANON_KEY=...
# SUPABASE_SERVICE_ROLE_KEY=...
```

> ⚠️ قانون اجباری: `.env.local` و هر فایل `.env*` هرگز کامیت نمی‌شود (در `.gitignore` آمده). هیچ سکرتی در گیت نباشد.

```bash
# ۳. اجرای مایگریشن دیتابیس (Supabase)
# فایل‌های داخل supabase/migrations را به‌ترتیب اجرا کن
# (مثلاً با supabase CLI یا از SQL Editor داشبورد Supabase)

# ۴. اجرای محیط توسعه
npm run dev
```

بعد مرورگر را باز کن: `http://localhost:3000`

## ساختار پوشه‌ها

```
thailandgard-dashboard/
├── app/
│   ├── dashboard/        # صفحه‌ی اصلی داشبورد (وضعیت چرخه و تیم‌ها)
│   ├── login/            # صفحه‌ی ورود
│   └── api/
│       ├── auth/         # لاگین/لاگ‌اوت
│       ├── cycles/       # API چرخه‌ها (ساخت، وضعیت، تاریخچه)
│       ├── teams/        # API تیم‌ها (اجرا، وضعیت، خروجی)
│       └── health/       # سلامت سرویس
├── components/           # کامپوننت‌های React داشبورد
├── lib/
│   ├── types.ts          # تایپ‌های دامنه: تیم‌ها، موج‌ها، چرخه، TeamRun
│   └── teams/            # منطق هر تیم (پرومت، ورودی/خروجی، حافظه)
├── supabase/
│   └── migrations/       # مایگریشن‌های SQL دیتابیس
├── .env.example          # نمونه‌ی متغیرهای محیطی (بدون مقدار واقعی)
└── README.md
```

## نکته‌های مهم

- ترتیب اجرای موج‌ها و فهرست ۱۵ تیم فقط در یک جا تعریف می‌شود: ثابت‌های `TEAMS` و `WAVES` در `lib/types.ts`.
- قبل از هر پوش، `git status` را چک کن که فایل سکرت (مثل `.env.local`) ناخواسته استیج نشده باشد.
